Database schema · Current implementation

MMS physical schema as implemented

Column-level foreign keys from the live Drizzle models in apps/backend/src/db/schema. Five subsystem panels stay inside the type budget. Edges are only declared FKs — indexed columns without a foreign key are not drawn. Tenant rows use composite (workspace_subdomain, id) unless noted.

Finance — invoices, lines, payments, fee catalog

Accounting — fiscal years, journals, accounts

PLATFORM

Platform apex — workspaces and operators

WHAT THIS FILE SHOWS

Spine of the implemented database

  • People: contacts, child collections, students, teachers, tenant_users
  • Academics: sessions, session_classes, enrollments
  • Finance: invoices, lines, payments, fee catalog
  • Accounting: fiscal years, entries, journal lines, accounts
  • Platform: workspaces, operators, permissions, activity logs

DECLARED FKS ONLY

No invented relationships

  • finance_invoices.student_id / enrollment_id are indexed, not FKs
  • attendance.class_id has no FK to session_classes
  • tenant_users.contact_id SET NULL exists; omitted here to stay on budget
  • Almost every tenant table FKs workspaces.subdomain ON DELETE CASCADE
